# Beyond Moore's Law

A web version of the ECE student article **Beyond Moore's Law: How Semiconductor Engineering Is Scaling After Transistor Shrinkage** by Heer Thakker and Dhruv Vaghela.

## GitHub Pages

After uploading this repository to GitHub:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select **main** and **/(root)**.
4. Save.

Your site will be available at:

`https://YOUR-USERNAME.github.io/beyond-moores-law/`

## Files

- `index.html` — complete article page
- `images/` — article figures embedded locally
